How It Works

API Architecture Today

01. Caller Sends Signature

POST /verify with an ML-DSA-87 public key, message, and signature. Stateless REST endpoint. Holds no keys, stores nothing.

02. Backend Verifies

Qubex verifies the ML-DSA-87 signature and signs the result with its own attestation key — returning a portable receipt in milliseconds.

03. Anyone Verifies the Receipt

The attestation is checkable independently against the public key at /attestation-key. You don't have to trust us — you can verify.
